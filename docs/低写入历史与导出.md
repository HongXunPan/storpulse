# 低写入历史与导出

## 1. 默认行为

- 历史默认关闭，启动和实时采样不会创建 SQLite 数据库。
- 提醒默认关闭，不提供自动阈值或推测阈值。
- 用户显式修改设置时可以写入系统偏好；这不是周期性采样写入。
- 数据库只在用户启用历史后创建于应用支持目录。

## 2. 分钟聚合与写入时机

分钟桶从 Rust 已校正的本次运行累计量计算，不直接累加未经解释的平台原始计数器。设备与应用保持独立记录，来源和完整性随桶保存。

内存摘要只在以下时机使用单个 SQLite 事务批量写入：

1. 距离上次批量写入至少五分钟；
2. 用户结束区间记录（内核观察会话）；
3. 应用正常退出；
4. 用户主动导出摘要。

不保存逐秒样本。区间记录在结束后写入；应用正常退出时会先结束仍在进行的记录，未结束会话不会伪造结束时间。历史关闭时，已结束记录只保存在本次运行的内存列表中，退出后清除。

## 3. 数据范围

SQLite 保存：

- 设备和应用分钟摘要；
- 用户显式阈值识别出的已结束活动；
- 已结束观察会话；
- 历史、保留期和提醒设置。

区间记录开始时自动生成默认名称，结束结果页可直接修改。名称属于本机交互元数据：启用历史时写入 SQLite，旧数据库自动补齐名称列；名称不进入隐私摘要导出。

默认保留七天，用户可选择 24 小时、7 天或 30 天。设置变更与每次批量写入都会应用保留期，手动清理使用事务删除全部摘要和会话。

## 4. 提醒门禁

只有同时满足以下条件才允许启用提醒：

- 读取阈值大于零；
- 写入阈值大于零；
- 最短持续时间大于零；
- 冷却时间大于零；
- 系统授予通知权限。

活动识别由 Rust 共享内核执行。冷却按应用标识分别计算；冷却期内的新活动仍可写入历史，但不重复通知。

## 5. 隐私导出

导出文件是 `schemaVersion = 1` 的 JSON 摘要，只包含：

- 时间范围和应用标识；
- 读取、写入、持续时间等计数；
- 指标来源和完整性；
- 观察会话的 Top 应用标识。

导出不包含展示名、文件路径、命令行、用户名、文件内容或数据库内部设置。保存位置由用户通过系统面板明确选择。

## 6. 当前验证层级

自动测试覆盖默认关闭不建库、分钟批量写入、保留期、手动清理、提醒完整配置、按应用冷却、区间记录命名与改名、旧库名称列迁移、会话落盘和隐私导出。测试数据库固定在源码仓 `.codex-tmp/`，不进入 Git。

当前仍未进行正式应用构建、启动交互、通知实机授权、异常退出恢复、长时间写放大测量或人工视觉验收。
