# StorPulse 共享内核契约

## 1. 边界

共享内核接收平台适配器产生的累计计数快照，负责差值、速率、重置、stale、应用聚合、内存趋势、持续 I/O 时长、活动识别和观察会话。

共享内核不知道文件路径、命令行、用户名、权限弹窗、窗口或设备句柄。macOS 当前是唯一经过阶段 0 验证的平台；可选的应用元数据字段只用于保留跨平台接口，不代表 Windows 已支持。

## 2. 输入快照

输入使用 UTF-8 JSON，当前 `schemaVersion` 为 `2`。核心字段：

- `capturedAt`：ISO 8601 墙钟时间；
- `monotonicNanoseconds`：严格递增的单调时间；
- `metricSource`、`metricScope`：数据源和范围；
- `freshness`、`completeness`：新鲜度与完整性；
- `processes`：以 `pid + startTimeTicks` 标识的累计计数；
- `devices`：以会话内稳定、平台命名空间化的 `deviceId` 字符串标识设备累计计数；该字段不包含设备序列号，macOS 当前使用 `macos:ioreg:<十进制注册表项 ID>`；
- `summary`：可读取、受限、已退出、无法映射的磁盘事件、ETW 事件或缓冲区丢失和采集耗时；
- 进程 CPU、内存与物理占用是可选辅助字段；平台不可读取或进程已退出时必须省略或使用 `null`，不得写成假零值。

同一身份计数器下降时，本窗口速率为未知，不产生负值。新身份的首个样本也没有当前速率。

`schemaVersion=2` 使用严格字段集合；未知字段会被拒绝，不允许调用方把路径、命令行或其他平台私有数据夹带进共享模型。扩展字段必须提升契约版本并同步跨语言测试。

## 3. 实时输出

输出 `RealtimeSnapshot` 包含设备、应用和进程三层：

- `schemaVersion`：与输入契约同步为 `2`；
- `devices[].deviceId`：原样保留平台适配器提供的设备身份，不把 Windows 磁盘编号伪装成 macOS IORegistry ID；
- `current`：当前速率；无法计算、失败或 stale 时为 `null`，不是零；
- `averageLastMinute`：有效差值窗口的一分钟平均值；
- `runReadBytes`、`runWriteBytes`：引擎本次运行累计；
- `continuousIoDurationMilliseconds`：连续出现非零差值的时长；
- `activeObservationSession`：进行中的手动观察会话摘要；
- `summary`：最后成功采样时间和不可观测数量。

Helper 只有在平台适配器提供同一 `applicationId` 且明确标记 `isHelper` 时才归并。普通子任务只使用 `launchedByApplicationId` 表达启动关系，不盲目并入父应用。

观察会话总量优先使用设备层；设备量不可用时才使用进程归因总量。两个口径不会相加、求最大值或计算未归因差额。

## 4. C ABI

公共头文件位于 `crates/storpulse-ffi/include/storpulse.h`。

| 函数 | 用途 |
| --- | --- |
| `sp_engine_create` / `sp_engine_destroy` | 创建和销毁不透明引擎句柄 |
| `sp_engine_ingest_json` | 批量摄入原始快照 |
| `sp_engine_snapshot_json` | 按调用方单调时间取得不可变实时快照 |
| `sp_engine_command_json` | 执行观察会话和活动策略命令 |
| `sp_engine_last_error_json` | 读取稳定错误信息 |
| `sp_buffer_free` | 释放 Rust 返回缓冲区 |

所有返回缓冲区必须且只能由 `sp_buffer_free` 释放。句柄必须且只能由 `sp_engine_destroy` 销毁；调用方不得缓存 Rust 内部地址。

## 5. 用户命令

开始观察：

```json
{"type":"start_observation","sessionId":"本机生成的标识","startedAt":"2026-07-30T10:00:00Z","monotonicNanoseconds":1}
```

结束观察：

```json
{"type":"stop_observation","endedAt":"2026-07-30T10:05:00Z","monotonicNanoseconds":300000000001}
```

活动识别默认关闭。启用时必须显式提供正数读或写阈值与最短持续时间；共享内核不内置未经校准的提醒阈值。

## 6. 验证边界

- Rust 单元测试证明差值、重置、PID 复用、stale、聚合、活动和会话行为。
- FFI 测试证明输入拒绝、缓冲区所有权和版本化 JSON 输出。
- Rust 测试不能替代 macOS 平台 API、界面、签名或长期性能验证。
