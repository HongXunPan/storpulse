# StorPulse 工程代码技术选型

## 1. 当前技术栈

- 共享领域与引擎：Rust 1.97.1 stable，使用 Rust 2024 edition。
- macOS 采集与界面：Swift 6.3、SwiftUI、AppKit、libproc、IOKit。
- macOS 持久化：系统 SQLite3；历史关闭时不创建数据库。
- 跨语言边界：稳定 C ABI，传递带版本号的批量 JSON 和显式释放缓冲区。
- macOS 进程边界：C 桥通过 `dlopen` 装载 Rust 动态库，Swift actor 独占引擎句柄；测试产物不进入版本库。
- 当前宿主：macOS 26.5、Intel x86_64；部署目标暂定 macOS 14。

## 2. 依赖准入

Rust 仅允许以下第三方运行依赖：

| 依赖 | 用途 | 许可证 | 平台与体积影响 | 不采用的替代方案 |
| --- | --- | --- | --- | --- |
| `serde` | 稳定领域模型序列化 | MIT / Apache-2.0 | 纯 Rust、三平台可用；只进入共享内核 | 手写解析易产生契约分叉 |
| `serde_json` | FFI 批量快照与隐私导出 | MIT / Apache-2.0 | 纯 Rust；每秒一次批量分配需阶段 0 测量 | 逐字段 C ABI 复杂且演进成本高 |

Swift 不引入第三方包，只使用系统框架。若批量 JSON 的 CPU 或分配开销超过阶段 0 可接受范围，停止继续 UI，实现定长 C 结构批量传输后再评估。

## 3. 默认执行规则

1. 平台 API 只存在于 `platform/macos`，不得进入 Rust 共享领域。
2. Rust 内核不得保存完整路径、命令行、用户名或文件内容。
3. 计数器下降必须解释为身份变化、重置或数据源变化，不产生负速率。
4. 共享快照只携带来源、范围、新鲜度和完整性，不把 macOS 结论写成 Windows 已支持。
5. 历史和提醒默认关闭；实时样本只保存在内存。

## 4. 最小校验点

- `bash scripts/validate.sh`：格式、Rust check/test/clippy、Swift test、文件预算和差异格式。
- `bash scripts/validate_stage0_macos.sh`：当前宿主 API、真实负载、受限比例和自身开销。
- 当前源码仓是 Swift Package；本机 `xcodebuild -list` 不识别裸包目录，因此现阶段以 `swift test` 为 Swift 门禁，建立正式 Xcode 工程后再补 `xcodebuild test`。
- 任一校验失败、平台指标无法解释或自身出现主动周期性落盘时必须停止。

## 5. 暂不验证

- Windows ETW 与 WinUI。
- Apple Silicon 与 macOS 14–25 实机。
- App Sandbox、签名、公证、安装、更新和卸载。
- 正式构建、归档、打包和发布。
